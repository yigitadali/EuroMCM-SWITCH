# Evidence and licensing

`raw/gsm8k_responses.csv` contains third-party observed responses and correctness labels from RouteLLM, not measurements collected by this team. RouteLLM commit `0b64fdafe049e596a3f5657c219329f24af24198` is pinned. Its Apache-2.0 license is retained at `raw/LICENSE`. The underlying GSM8K license (MIT, OpenAI 2021) is retained at `raw/GSM8K_LICENSE`. Preserve both when redistributing. Source URLs and SHA256 hashes are in `source_manifest.json`. Downloaded files are unchanged; processed extracts are new transformations. No weight files are redistributed. RouteLLM's generator and contamination list are included to document evaluation and exclusions. The unused upstream `benchmarks.py` is reference code only, never executed.

The original generator uses an eight-shot prompt, temperature zero, and the last digit sequence of a response to score answers. We evaluate the stored Boolean labels and call the metric **published-label accuracy**. This is not independent human assessment of reasoning or a guarantee of correct numeric parsing. We report an additional conservative numeric-extraction discrepancy check; it does not relabel the benchmark.

We exclude exact prompt matches from the upstream contamination list, check unique prompts and Boolean labels, and save row IDs, prompt hashes, length features, answer features, and paired outcomes in `processed/benchmark.csv`. Split assignments are saved for every seed. Test labels are used only after policy selection. No confidence probabilities, latency, energy, additional-effort responses, or historical cost measurements are present in this benchmark. Relative cost comparisons assume the draft's 1:5.5 ratio and include all cascade calls.

`original_claims.csv` is a transcription of unverified draft claims. `results/` contains generated outputs. Synthetic input and potential-outcome arrays are saved in compressed NumPy format, explicitly separated from the benchmark. RouterBench was considered but not used because its dataset card did not specify an explicit dataset license; a code repository license alone was not treated as sufficient evidence of dataset licensing.
