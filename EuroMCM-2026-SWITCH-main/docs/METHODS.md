# Methods and choices fixed before inspecting the new outcomes

## Evidence layers

1. The original document is a specification with unverified result claims, not an executable experiment. Its single-seed numbers are not reused as evidence.
2. The paired RouteLLM GSM8K responses are observations collected by the upstream authors. We replay stored outcomes; we do not rerun inference or reproduce RouteLLM's trained router.
3. The SWITCH reconstruction, including all reasoning, confidence, electricity, carbon, queues, and outage calculations, is synthetic. It tests conditional implications, not real-world effectiveness.

## Synthetic reconstruction

Each seed has 450 training and 1,200 test requests. The four category shares and difficulty centres follow the draft. Missing difficulty SD is set to 0.10 before clipping to [0,1]. Pre-response noise SD is 0.14. Quality curves, resources, quality thresholds, 70:30 structural/history weights, 30% audit probability, fixed cutoffs and effort formula follow the draft. The four ablation variants share feedback, thresholds, workloads, random potential outcomes and router overhead. Basic has S/L choices; reasoning enables an extra R choice and optimizes its effort; cascade adds post-response escalation. Full SWITCH enables both. Thus 'reasoning' includes both availability of R and its optimized effort, not a clean causal test of optimization versus fixed R effort. The fixed baseline uses R effort 1.

For unspecified synthetic correctness dependence, a Gaussian common factor with rho=0.5 generates uniform quantiles for S/R/L, then outcomes compare those quantiles with the documented probabilities. Changing R effort reuses its quantile. Correct-answer scores have Beta(6,2) distribution; wrong-answer scores Beta(2,5), with overlap. This construction **assumes** access to an informative signal and is not a trained classifier. Mixing scores with independent uniform values and adding signed score bias tests failure. The policy sees the score, not correctness; a 30% audit updates only calls already completed. Each training request supplies all three synthetic labels; this unrealistic data availability and omitted training/audit costs are limitations.

The initial route is cheapest among predicted-feasible choices, otherwise L with a review flag. S can escalate directly to L in the no-reasoning variant; with reasoning the chain is S/R/L. All costs, energy and latency add over every call. Replacement of an accepted answer can harm accuracy; no hidden correctness-based selection chooses the final answer. A flag is not simulated human review. In an outage, an initial L call falls back to fixed-effort R where no optimized reasoning option exists; escalation to unavailable L stops. No quality claim includes hypothetical human correction.

The main ablation uses identical original locations for all policies, isolating inference policy from siting. Relocation is a separate scenario; all compared policies have the same relocation eligibility. Sixty percent originate at 400 g/kWh, 40% at 120. Sixty percent are urgent; half of nonurgent high-intensity requests have spare destination capacity. Eligible moved tasks add 0.2 cost units, 0.75 s and 0.15 Wh, charged at destination intensity. Routing and effort use the original intensity before relocation. This makes the implementation's order explicit; it is not joint scheduling optimization. Constant coordination electricity is also charged at the processing site. The queue delay 0.35*l/(1-l) is phenomenological, shared by policies, and not a capacity simulator. No requests are dropped; high demand changes waiting time only.

Thirty independently spawned seed streams generate new synthetic workloads and outcomes. Common random numbers within each seed make policy comparisons paired. Seed-level SD and empirical 2.5/97.5 percentiles describe Monte Carlo variability, not uncertainty about real models or confidence intervals for real deployment. Separate scenario tests use the same seed streams, with only the named assumption changed. Model performance shifts apply to S/R/L together; effort-benefit multiplier tests the unvalidated reasoning benefit; rho tests dependence. Hard-mix changes workload shares. We do not search for parameters that reproduce the original table.

## Observed-response benchmark

We use every eligible GSM8K row, exclude upstream contamination matches, and check unique prompts and truth joins. The metric retains upstream Boolean labels. For each of the same 30 seeds, a new random split allocates 60% training, 20% validation and the rest test. These test sets overlap across seeds: their variation is split sensitivity, **not 30 independent inference runs or 30 independent benchmark samples**. The main observed model accuracies on all 1,307 eligible rows are reported separately from split means.

The pre-response score is a training success fraction in prompt-word-count terciles. The post-response score is a training success fraction in six bins: weak-response word-count tercile crossed with presence of `####`. Five pseudo-observations at the overall training success rate stabilize bins. Cutpoints and estimates use training data only. These modest features are chosen for transparency, not claimed to be a state-of-the-art router or semantic correctness verifier. Response features are available only after paying for the weak call. We never inspect a strong response before choosing it.

Validation chooses the least costly pair of pre/post thresholds meeting 95% of validation strong-model accuracy, with accuracy as a tie-breaker. Test labels do not select thresholds. The criterion is a validation target, not a test guarantee. Baselines include always weak/strong, random direct routing with the basic router's same strong-call count, and an explicitly unattainable label-aware upper bound with at most that call budget. The oracle only escalates positive weak-to-strong gains. It is not a proposed policy. Basic and cascade costs use 1 for Mixtral, 5.5 for GPT-4 and 0.12 overhead; these are **assumed relative costs**, not historical or current prices. A cascade pays for both calls. No measured carbon or latency is inferred from this replay. Additional reasoning is absent from the records, so the four-way ablation is restricted to the synthetic experiment.

The benchmark reveals whether this simple real scorer separates successes from failures and whether the routing rule generalizes. It cannot validate policy-analysis, multilingual government use, model energy, a reasoning-effort curve, or the draft's absolute performance assumptions. Parser sensitivity compares last signed/decimal number extraction with the ground-truth final numeric answer and counts differences against published labels. This flags scoring sensitivity without claiming the alternative parser is a definitive human adjudication.

Supplementary fixed-effort controls enable R with x=1, with and without cascade. These separate the availability of an R route from the benefit of optimizing effort. Training R outcomes use the same effort rule as the evaluated variant: effort optimized from noisy estimated difficulty, or fixed x=1. In performance and reasoning-benefit sensitivity tests the router retains its baseline structural curve; synthetic training/audited outcomes reflect the changed actual curve. It does not receive the true changed curve as a prediction input.
